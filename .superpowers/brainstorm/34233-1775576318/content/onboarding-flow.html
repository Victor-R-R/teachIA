Flux onboarding — teachIA

Première ouverture de l'app. 3 étapes, puis le dashboard.

1
📅 Date du concours
"Quand passes-tu le CAPES ?"
→ Calcul automatique des semaines restantes
→ Définit l'intensité du plan
Ex : 12 semaines → plan intensif
Ex : 6 mois → plan progressif
2
🎯 Test de niveau
15 questions rapides :
5 langue · 5 civilisation · 5 didactique
→ Score A / B / C par domaine
Résultat : { langue: B,
  civilisation: A,
  didactique: C }
3
🗓️ Plan généré par IA
L'IA génère un plan semaine par semaine basé sur les niveaux détectés et le temps restant. Priorité aux points faibles.
Semaine 1 : Civilisation (prioritaire)
Semaine 2 : Grammaire + Civi
Semaine 3 : Didactique…
✓
🏠 Dashboard
Plan de la semaine, score de préparation, exercices du jour, accès rapide au professeur IA.
Données persistées après onboarding
user_profile: { exam_date, levels: {langue, civi, didactique} }
study_plan: [ { week: 1, domain, objective, target_date }, … ]

Stocké dans Neon Postgres. L'onboarding ne se déclenche qu'une seule fois (si user_profile n'existe pas).
